# Progress tracker

Tick as you go. An honest tracker with gaps is more useful than a fake complete one.

## Weekly milestones

- [ ] **Week 1 (Sep 1-6)** - A multi-tier application running on AWS that you built and can explain, plus a clean AWS account afterwards.
- [ ] **Week 2 (Sep 7-13)** - A Jenkinsfile in your repo that builds, tests, analyses and publishes an artifact automatically.
- [ ] **Week 3 (Sep 14-20)** - The same pipeline expressed three ways (Jenkins, GitHub Actions, GitLab) and a written comparison.
- [ ] **Week 4 (Sep 21-27)** - Infrastructure you can create and destroy with two commands, plus a Python tool that audits your own AWS account.
- [ ] **Week 5 (Sep 28-Oct 4)** - A server you never configured by hand, and a dashboard that tells you when it breaks.
- [ ] **Week 6 (Oct 5-11)** - A production-shaped private network, and an application deployed into it by a pipeline you did not touch.
- [ ] **Week 7 (Oct 12-18)** - The entire application stack running from a single `docker compose up`, with published images.
- [ ] **Week 8 (Oct 19-25)** - The application running on Kubernetes from a Helm chart, on a cluster created by Terraform.
- [ ] **Week 9 (Oct 26-31)** - A complete GitOps capstone: commit to Git, and the change reaches a live Kubernetes cluster on its own.
