docker volume create application-backup

To know how to use the volume:
- docker volume create application-backup creates a persistent storage volume.
- -v application-backup:/usr/share/nginx/html mounts that volume into the Nginx container at the folder where Nginx serves web files.
- -p 5052:80 maps port 5052 on the host to port 80 inside the container.
- --name nginx-application gives the container a name.
- nginx is the image used to run the web server.

Note: the correct Nginx folder path is /usr/share/nginx/html (not /usr/share/nginx.html).

docker run -d -p 5052:80 --name nginx-application -v application-backup:/usr/share/nginx/html nginx
